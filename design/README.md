# Design source

`canvas/` holds the source of the Phase 2 design canvas: one `.dc.html` file per screen,
plus `canvas.json` for the layout. The canvas itself is hosted as a private Claude
artifact. These files are kept here for version history and as a reference for Phase 3.
They are mockups with sample data, not application code.

See [../docs/DESIGN_SYSTEM.md](../docs/DESIGN_SYSTEM.md) for tokens, components and rules.
